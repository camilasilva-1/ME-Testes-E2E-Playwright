# M.E. — Testes E2E com Playwright

Projeto da disciplina de **Testes de Software** para automatizar testes de sistema usando **Python, Playwright e pytest**.

**Aplicação testada:** [Projeto-Metaforando](https://github.com/Gioh-jpg/Projeto-Metaforando), protótipo de reconhecimento de expressões faciais.

## Cenários planejados

1. **Sucesso:** selecionar uma imagem válida e verificar a pré-visualização.
2. **Erro:** enviar um arquivo inválido e verificar o alerta.
3. **Fluxo completo:** selecionar, visualizar e remover uma imagem.

**Status:** em desenvolvimento. A integração com o modelo de IA ainda não está concluída.

As instruções de execução serão adicionadas com os testes.
