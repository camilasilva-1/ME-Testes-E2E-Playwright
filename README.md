# M.E. — Testes E2E com Playwright

Projeto da disciplina de **Testes de Software**, utilizando **Python, Playwright e pytest** para automatizar testes de uma aplicação web.

## Sistema utilizado

Vamos testar o [Projeto-Metaforando](https://github.com/Gioh-jpg/Projeto-Metaforando), desenvolvido na disciplina de IA e Data Science para reconhecimento de expressões faciais.

Atualmente, o sistema possui um protótipo de interface. A integração com o modelo de IA ainda está em desenvolvimento.

## Testes planejados

1. **Sucesso:** selecionar uma imagem e verificar se a pré-visualização aparece.
2. **Erro:** tentar enviar um arquivo inválido e verificar se o sistema apresenta um alerta.
3. **Fluxo completo:** selecionar uma imagem, visualizá-la e removê-la, verificando cada resultado.

## Tecnologias

- Python
- Playwright
- pytest
- HTML, CSS e JavaScript (aplicação testada)
